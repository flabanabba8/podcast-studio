# podcast-studio: setup and task guide

Source-reviewed 2026-11-09. Use [actual schemas](contracts.json) for argument details.

## Setup and speech choices

A topic and intended audience come before a cast or backend. For a CPU/offline/no-subscription user, use recorded speech or an installed lightweight TTS when its quality and license fit. A capable GPU can use an already-available local voice system. A user-selected remote speech endpoint can supply speech after confirming API entitlement, consent, budget and upload scope. Do not assume PageCast, a particular voice, Higgs or a second LLM is required. Reason and write within the active host. Compare real short voice samples only when needed; a saved budget is not an enforced spend cap.

## Worked researched episode

For a beginner photography discussion, podcast_start_topic records the audience and resources. Read the actual guide through a native browser/search or podcast_research_fetch using an already-installed Camoufox Python and executable. The browser has no borrowed login profile, blocks heavy assets and returns untrusted text. Check title, body completeness, dates and relevant claims; add alternative sources explicitly if blocked. Source pages must be read before a factual script can reference them. This mechanical gate cannot certify understanding, independence or truth.

Write a concise opening situation, useful example, explanation and takeaway as host turns with source IDs. podcast_write_script creates the real episode text folder. Apply the existing editorial and source-check process, then render the selected voices without silently changing the cast. Normalize actual speech WAVs to one sample rate, mono16-bit PCM, and attach them in turn order. Assemble and inspect the measured timeline. Optional music mixing follows assembly and needs a new listening/timing check. Export audio, notes and reviewed captions; no upload occurs.

## Diagnose and accept

Botwall or timeout: keep diagnostics, select another legitimate source or a supported selected tool; do not pretend the page was read. A second speech recognizer or source repeating a claim is not independent fact-checking. A project with script but no attached speech is not a finished podcast. Empty/mismatched WAVs or changed material stop assembly. Image attachments additionally need Pillow, not required for audio-only production. Acceptance means clear listener-friendly dialogue, checked sources, actual clean audio, reviewed names/pronunciation/levels/timing and retained rights/credits. Hash review gates remain self-attested mechanical evidence.
